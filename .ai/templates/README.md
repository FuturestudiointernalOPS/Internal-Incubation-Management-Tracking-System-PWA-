# Templates

Reusable output templates for the Engineering Runtime (`.ai/`).

| Template | Used by skill | Produced when |
|---|---|---|
| `implementation-report.md` | feature | feature Completed |
| `bug-fix-report.md` | bug-fix | bug-fix Completed |
| `forensic-report.md` | forensic | forensic Completed |
| `database-plan.md` | database | database Completed |
| `review-report.md` | review *(add the skill to activate)* | review Completed |

To add a template: drop a file here with a `name` / `purpose` / `used_by` header, then reference it from the relevant skill's **Output Template** section.
